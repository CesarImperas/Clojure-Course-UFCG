Caio Cesar Vieira Cavalcanti - 30/04/2025

## Using Clojure

The Snake game is based on the original arcade game, which the player needs to move the snake using WASD (Up, Left, Down and Right, respectively), in search of eating all the fruits (`*`), without the snake crashing into the board barrier or itself.

## How to play?

In terminal, use the command `clj -M snake-game.clj`.

** Make sure you have the Clojure CLI installed on your machine! **
** Additional, you need installed on your machine the JLine library, for this, you use the command `clj`, It will install this dependecy on your system! **
