# Project - Snake Game in Functional Programming

Caio Cesar Vieira Cavalcanti - 30/04/2025

## Using JavaScript (Node.js)

The Snake game is based on the original arcade game, which the player needs to move the snake using WASD (Up, Left, Down and Right, respectively), in search of eating all the fruits (`@`), without the snake crashing into the board barrier or itself.

## How to play?

In terminal, use the command `node snake-game.js`.

** Make sure you have the *Node.js* installed on your machine! **
