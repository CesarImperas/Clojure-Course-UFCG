# Programação Funcional

1. Em um diretório `snake-js`, usando JavaScript (Node), escreva
   uma versão simples do clássico jogo arcade chamado Snake,
   usando um estilo funcional de programação. Restrinja-se ao
   máximo a funções puras e isole/reúna as partes não funcionais
   (entrada e saída, persistência, etc).

   > Detalhes do jogo. A interface deve ser no terminal mesmo,
   > com bastante simplicidade. Observe que você precisará usar
   > alguma forma simples de manipular o terminal. O mais simples
   > é usar/imprimir códigos ANSI diretamente, mas você pode
   > preferir usar alguma biblioteca node simples pra manipulação
   > de terminal. Se for preferir isso, você deve contactar os
   > monitores e ver a possibilidade de instalá-la na VM.

2. Em um diretório `snake-clj`, reescreva o jogo, usando Clojure.
   Observe que quase que uma tradução literal do jogo feito em JS
   para Clojure deve funcionar, no mínimo para as partes
   puramente funcionais.

   > Mais uma vez, você pode usar meros códigos ANSI para
   > manipular o terminal ou pode preferir alguma biblioteca
   > simples. Da mesma forma, você deve consultar os monitores
   > para verem a possibilidade de instalar qualquer biblioteca
   > antes de comprometer o projeto com ela.
